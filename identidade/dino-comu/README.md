# Dino Comu

Identidade visual "Dino sério", criada para o Comunique e guardada aqui para reutilizar em outros projetos.

## Cores

| Nome | Hex | Uso |
|---|---|---|
| Floresta | `#14352B` | topo, botões principais, texto |
| Jade | `#1F8A5B` | símbolo e enfeites (não para texto pequeno) |
| Jade texto | `#18774E` | links, foco, botões com texto branco |
| Âmbar | `#E8A33D` | atenção: aba atual, alertas, novidades (sempre com texto floresta) |
| Areia | `#F4EFE6` | destaque, item ativo, tela de entrada |
| Fundo | `#FAF7F1` | fundo da página |

Tema escuro: verde-noite (`#0F1C17` fundo, `#16261F` superfícies, `#6CCB9A` destaque). Tudo em `tokens.css`.

## Tipografia

- **Manrope** 700–800 nos títulos e números grandes.
- **Inter** 400–600 no texto, tabelas e números.

## Símbolo

Cabeça de dino geométrica com duas plaquinhas âmbar.

- `simbolo.svg`: no quadrado jade (ícone de app, favicon).
- `simbolo-sem-fundo.svg`: o dino em floresta, para fundos claros.
- `icones/`: PNG prontos (512, 192, maskable 512, apple-touch 180, favicon 32).

Tamanho mínimo: 24 px. Não distorcer, não trocar as cores do dino, não pôr sombra.

## Voz

Direta, calma e confiável.

- Saudação: "Bom dia, Fulano. 6 itens aguardam você."
- Sucesso: "Cadastro aprovado. Quem enviou já foi avisado."
- Tela vazia: "Tudo em dia por aqui."

## Regras

- O nome do produto aparece por inteiro ("Comunique" no Comunique); o dino é o símbolo, não troca o nome.
- Texto sempre com contraste de pelo menos 4,5:1 (por isso o "jade texto" existe).
