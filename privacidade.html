Política de Privacidade — Cadastro de Entregadores

Última atualização: 14 de novembro de 2026

O Cadastro de Entregadores é uma ferramenta interna, de uso restrito a pessoas autorizadas, para registrar e analisar cadastros de entregadores. Esta página explica quais dados são tratados e como.

1. Dados de quem usa o sistema

Ao entrar com a conta Google, recebemos apenas o nome e o endereço de e-mail da conta. Eles servem para identificar a pessoa, conferir se ela tem acesso e registrar quem fez cada ação (envio, aprovação, reprovação ou encerramento). Não acessamos contatos, arquivos, e-mails nem qualquer outro dado da conta Google.

2. Dados dos entregadores

A equipe autorizada registra, para cada entregador: ID no aplicativo de entregas, nome, cidade e observações sobre a operação (ativação, restrições, valores pagos fora da corrida). Esses dados são usados exclusivamente para a análise e o acompanhamento da operação. O Comunique não guarda CPF.

3. Extensão do Comunique para o Chrome

A extensão do Comunique é usada só pela equipe autorizada, com a mesma conta Google do sistema. Ela:

  • mostra no ícone o número de avisos e as notificações do Comunique, consultando o mesmo banco de dados;
  • nas telas de entregador do painel Quero Log (admin.querolog.io) e do Crisp (app.crisp.chat), lê somente o ID, o nome e a cidade do entregador para abrir o formulário do Comunique já preenchido. Celular, e-mail, CPF, endereço e qualquer outro dado da tela não são lidos;
  • não envia nada sozinha: os dados só são gravados quando a pessoa confere o formulário e confirma;
  • guarda no próprio navegador apenas a sessão de login e quais avisos já foram mostrados.

A extensão não lê nenhum outro site, não acompanha a navegação e não usa os dados para publicidade.

4. Onde os dados ficam

Os dados são armazenados num banco de dados do Supabase, com acesso controlado: cada pessoa só vê o que o seu nível de acesso permite. O login é feito pelo Google e pelo Supabase.

5. Compartilhamento

Os dados não são vendidos nem compartilhados com terceiros, exceto os provedores de infraestrutura citados acima, que os processam apenas para o funcionamento do sistema.

6. Por quanto tempo

Os dados ficam guardados enquanto forem necessários para a operação. O acesso de uma pessoa ao sistema pode ser removido a qualquer momento pelos responsáveis.
